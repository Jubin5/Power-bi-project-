# COVID-19 Data Analysis Using Power BI

## Project Overview
This project focuses on analyzing COVID-19 data using **Power BI** to derive insights from global pandemic trends. The dashboard provides interactive visualizations, enabling better understanding of cases, deaths, and recovery trends over time and across different regions.

## Dataset
- **Source:** Publicly available COVID-19 dataset (e.g., WHO, John Hopkins University, Kaggle)
- **Data Attributes:**
  - Date-wise cases, deaths, and recoveries
  - Geographical distribution (country/region-wise data)
  - Testing statistics and vaccination progress
  
## Objectives
- Visualize COVID-19 trends using Power BI dashboards
- Analyze the impact of the pandemic across different regions
- Compare vaccination rates and case fatality ratios
- Identify peak infection periods and trends

## Power BI Dashboard Features
- **Global Overview:** Summary of cases, deaths, and recoveries
- **Regional Analysis:** Country-wise and continent-wise comparisons
- **Time-Series Analysis:** Trends in cases and deaths over time
- **Vaccination Insights:** Impact of vaccines on infection rates
- **Filtering Options:** Interactive slicers for dynamic analysis

## Key Insights
- Identification of high-risk regions based on case density
- Correlation between vaccination rates and case reduction
- Peak infection waves and their impact over time

## Future Enhancements
- Incorporating real-time data updates
- Adding predictive analytics for trend forecasting
- Enhancing interactivity with advanced Power BI DAX functions

## Installation & Usage
1. Download the Power BI file (.pbix) from the repository.
2. Open with **Power BI Desktop**.
3. Ensure data sources are connected and refresh the dataset.
4. Explore the interactive visualizations.

## Conclusion
This Power BI dashboard provides an intuitive and data-driven approach to understanding COVID-19 trends. It serves as a powerful tool for researchers, policymakers, and the general public to track the pandemic’s impact effectively.
